\## Overview



Piqqudim is building an ecosystem of technology spanning software development, graphics, game technology, 3D design, digital commerce, and interactive entertainment.



The corporate website serves as the central online identity of the company. It introduces visitors to Piqqudim, communicates its direction, provides information about the team, and creates a clear path for potential employees, collaborators, partners, and customers to connect with the company.



\### Primary objectives



\* Establish a recognizable and professional Piqqudim brand.

\* Communicate the company's vision, mission, and areas of focus.

\* Introduce the Piqqudim ecosystem without making the homepage product-centric.

\* Present the people and culture behind the company.

\* Publish career opportunities and provide a clear application process.

\* Share company announcements, engineering updates, and news.

\* Provide accessible contact channels for professional inquiries.

\* Create a scalable foundation for future company growth.



\## About Piqqudim



Piqqudim is a technology company focused on building software, platforms, and digital experiences.



Its interests span multiple areas of technology, including game development, graphics and rendering, programming tools, 3D design, digital commerce, and interactive entertainment.



Piqqudim aims to build technology that enables people to create, develop, connect, and participate in an increasingly digital world.



The company website communicates this broader purpose rather than presenting Piqqudim as a single-product business.

\### Mission

\## Careers and Open Positions



Piqqudim's careers experience is an important part of the corporate website.



The goal is to help talented people understand the company, discover opportunities, review role requirements, and apply through a clear process.



\### Careers landing page



The careers page should communicate the opportunity to help build Piqqudim and contribute to its technology ecosystem.



Suggested headline:



\*\*Build the future with us.\*\*

\* Location.

\* Make application instructions easy to understand.

\* Protect applicant information and restrict access to recruitment data.

\* Provide a clear way to close or archive filled positions.

\## Design Philosophy



The Piqqudim corporate website should have a premium, modern technology-company aesthetic.



Its design may take inspiration from the clarity, strong visual hierarchy, and technical presentation of established technology companies while maintaining an original Piqqudim identity.



\### Visual direction



\* Dark charcoal and near-black backgrounds.

\* White and light-gray typography.

\* Electric blue and violet accents.

\* Large, confident headings.

\* High-quality abstract, architectural, or technological imagery.

\* Restrained gradients and subtle animations.

\* Clear section hierarchy.

\* Generous spacing and uncluttered layouts.

\* Responsive layouts for desktop, tablet, and mobile.



\### Brand positioning



Piqqudim should look like a technology company capable of developing multiple products across different industries.



The site should not look exclusively like a game studio, an e-commerce store, or an individual game engine landing page.



\### Design priorities



1\. Company identity comes before product promotion.

2\. Readability comes before decorative effects.

3\. Consistency comes before unnecessary complexity.

4\. Accessibility is part of the design process.

5\. Performance matters more than excessive animation.

6\. New products and pages must fit into the existing design system.

\## Getting Started



\### Prerequisites



Before running the project, install:



\* Node.js, preferably an active LTS release compatible with the chosen framework.

\* npm or another supported package manager.

\* Git.

\* A code editor such as Visual Studio Code.



\### Installation



Clone the repository:



```bash

git clone <YOUR\_REPOSITORY\_URL>

cd piqqudim-website

```



Install the dependencies:



```bash

npm install

```



Start the development server:



```bash

npm run dev

```



Open the local development address shown in the terminal. For a typical Next.js development server, this is:



```text

http://localhost:3000

```



The exact commands depend on the scripts configured in `package.json`.



\### Production build



Create a production build:



```bash

npm run build

```



Run the production server locally, if supported by the project:



```bash

npm run start

```



Before deployment, verify that the production build completes successfully and that all routes, assets, and navigation links work correctly.

\## Development Guidelines



\### Component architecture



Use reusable components for shared elements such as:



\* Header and navigation.

\* Footer.

\* Buttons and links.

\* Section headings.

\* Product summaries.

\* Job cards.

\* News cards.

\* Responsive containers.



Avoid duplicating large blocks of markup across pages.



\### Content management



Keep repeated content in structured data files or an appropriate content source rather than embedding the same information throughout multiple components.



\### Product independence



The corporate website should not depend on individual products being complete or publicly released.



Each product should be represented with an appropriate description and destination. Unavailable product pages should not be presented as functional.



\### Maintainability



\* Use descriptive names for files and components.

\* Keep components focused on a clear responsibility.

\* Avoid unnecessary abstractions.

\* Use TypeScript where supported.

\* Keep dependencies to a minimum.

\* Document configuration that requires manual setup.

\* Never commit secrets, API keys, or private credentials.



\### Version control



Use Git to track changes and preserve stable versions of the website.



Suggested commit messages:



```text

feat: add corporate homepage

feat: implement careers and job listings

feat: add company information pages

feat: introduce responsive navigation

fix: improve mobile layout

fix: resolve broken navigation links

docs: update project documentation

```

\## Accessibility and Performance



The website should follow modern web accessibility and performance practices.



\### Accessibility



\* Use semantic HTML.

\* Provide descriptive alternative text for meaningful images.

\* Ensure keyboard navigation works.

\* Maintain sufficient text contrast.

\* Label form fields clearly.

\* Provide visible focus indicators.

\* Respect reduced-motion preferences.

\* Avoid relying on color alone to communicate information.



\### Performance



\* Optimize image sizes and formats.

\* Avoid unnecessary JavaScript.

\* Use responsive images where appropriate.

\* Lazy-load suitable below-the-fold media.

\* Limit animation complexity.

\* Minimize layout shifts.

\* Monitor production performance as the site grows.



\### Responsive design



The website must work across:



\* Desktop computers.

\* Laptops.

\* Tablets.

\* Mobile phones.



Content should remain readable and navigation usable at different viewport sizes.
